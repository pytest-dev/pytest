:meth:`MonkeyPatch.setenv <pytest.MonkeyPatch.setenv>` now issues a :class:`~pytest.PytestWarning` when ``prepend`` is used on an environment variable that is set but empty, since an empty value means different things for different variables (an empty entry in ``PATH`` is the current directory). The new ``empty`` keyword argument chooses the result and silences the warning: ``"keep"`` gives ``value + prepend`` (the current behavior) and ``"skip"`` gives just ``value``.
