When ``BdbQuit`` is raised during a run, for example when quitting the debugger with Ctrl+D, pytest now fails the current test and stops the test run. Previously the remaining tests still ran on Python 3.13 and earlier, while on 3.14 the run stopped without reporting the failure. This is now the same on all supported Python versions. Quitting with the ``q``/``quit``/``exit`` commands still stops the run without failing the current test -- by :user:`EternalRights`
