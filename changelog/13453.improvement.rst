When ``BdbQuit`` is raised during a run, for example when quitting the debugger with Ctrl+D, pytest now fails the current test and stops the test run. Previously the session continued with the remaining tests, silently skipping teardown. This is now the same on all supported Python versions. Quitting with the ``q``/``quit``/``exit`` commands still stops the run without failing the current test -- by :user:`EternalRights`
