Fixed two races between pytest runs that clean up the same temporary directory root at the same time, such as concurrent runs by one user: one run's removal of an old temporary directory could fail with ``PytestWarning: (rm_rf) error removing ... Directory not empty``, and with ``-W error`` or ``filterwarnings = error`` that run then failed after all of its tests had passed. In one of the two races, the directory was also left behind until its lock was three days old.
